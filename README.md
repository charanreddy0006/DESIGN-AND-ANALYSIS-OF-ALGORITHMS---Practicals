# Design and Analysis of Algorithms (DAA) Lab

This repository contains the laboratory programs and practical implementations completed as part of the **Design and Analysis of Algorithms (DAA)** course during the 5th semester of my B.Tech in Computer Science and Engineering (AI & ML).

The repository covers fundamental algorithms, problem-solving techniques, algorithm design strategies, and complexity analysis implemented using C++.

## 📂 Repository Contents

This repository contains 12 practical implementations covering sorting, searching, dynamic programming, graph algorithms, greedy algorithms, and optimization problems.

| No. | Practical / Experiment | Topics Covered |
|---|---|---|
| 01 | Sorting Algorithms | Bubble Sort, Selection Sort, Insertion Sort, Merge Sort and Quick Sort |
| 02 | Searching Algorithms | Linear Search and Binary Search |
| 03 | Max-Heap Sort | Implementation of Max-Heap Sort Algorithm |
| 04 | Factorial Implementation | Iterative and Recursive Methods with Time Analysis |
| 05 | Knapsack Problem | Dynamic Programming Approach |
| 06 | Matrix Chain Multiplication | Dynamic Programming Approach |
| 07 | Making a Change Problem | Dynamic Programming Approach |
| 08 | Graph Traversal | Depth First Search (DFS) and Breadth First Search (BFS) |
| 09 | Prim's Algorithm | Minimum Spanning Tree (MST) |
| 10 | Kruskal's Algorithm | Minimum Spanning Tree (MST) |
| 11 | Floyd-Warshall Algorithm | All-Pairs Shortest Path |
| 12 | Travelling Salesman Problem | Minimum Cost Tour using Backtracking |
